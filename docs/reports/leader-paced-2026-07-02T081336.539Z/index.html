Methodology

What was sentMemo-free self-transfer with compute budget instructions. Fees and route tips are read from signed transaction metadata and observed route-tip signatures.
Landing clockLatency uses the first matched observation across configured streams. Usually this is SubscribeDeshred; processed is used when it is first or only.
Block positionTransaction index comes from Yellowstone processed metadata, because deshred observations normally do not carry canonical block index.
What ACK meansACK is retained only as a sender diagnostic. It is not leader admission, not landing proof, and not used as the product latency claim.
Generated only from local benchmark artifacts. Leader metadata comes from saved getLeaderSlots snapshots captured during the run; no ClickHouse or private database join is required.
