Methodology

Paired design

Both transactions share the leader run, slot trigger, sender host, transaction shape, and fee configuration. Only the network route differs.

Same-slot rule

First-observation time, processed transaction index, entry index, and PoH interval are compared only when both signatures land in the same slot.

Observation clock

Each signature uses its earliest event across the configured RPCEdge receivers. Deshred and processed receivers are not compared with each other.

Block placement

Processed transaction index is canonical transaction order. Entry index and preceding PoH ticks are derived after collection from the saved contiguous entry history.

Interpretation

Observation time includes sender scheduling, network transit, leader admission, block production, and propagation to the Frankfurt observer. It is not network RTT or TPU packet-arrival latency.

Geography

City, country, latitude, and longitude are historical values saved in getLeaderSlots snapshots. The coarse region classifier is not used.

The report does not claim that repeated transactions from one validator are independent samples or that geographic distance alone caused an observed difference.
